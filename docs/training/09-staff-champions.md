# Staff champions (optional)

Pairs with All phases. 90 to 120 minutes, hands on.

**Goal:** Help colleagues get value from the chat.

## Exercise

1. Pick the right model spec for a task; use the prompts library with variables.
2. Temporary chats, chat projects, forking and branching, side-by-side comparison, bookmarks, conversation search.
3. The context usage gauge; dictation and read-aloud; importing a ChatGPT export.

## Expected result

Each champion can show three features to a colleague.
